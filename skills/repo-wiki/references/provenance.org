* Local adaptation

This skill uses the host agent's repository tools and writes Org documentation.
It integrates with existing glossaries, ADRs, Emacs editing, and Org validation.
It does not install OpenWiki or reproduce its MCP protocol, OKF metadata,
Claims engine, source-version verification, durable page queue, or finalization.

Org revision properties and source links are manual review aids. They do not
provide OpenWiki's runtime guarantees. The skill does not manage an existing
OpenWiki installation or its metadata; use the upstream workflow for that task.
